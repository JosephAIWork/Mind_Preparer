# Internal notes

Internal to Milliman Tel Aviv, like `use-case-notes/`. These files sit outside the app
(`excel-upload-preparation`) and are never part of a hand-over or of the repository given to the Mind
team. They name client models, sheets and cells.

| File | What it is |
|---|---|
| `CHANGELOG_to_1.11.10.md` | The full development changelog up to 1.11.10, with the measurements on the client models. The app's own `CHANGELOG.md` starts again from the hand-over. |
| `AUTOFIX_RUN_LOG.md` | The log of the first auto-fix runs (2026-10-05). |
| `AUTOFIX_USE_CASES.md` | What the auto-fix did on each test model. |
| `CHANGES_2026-09-27_to_2026-09-30.md` | Change notes for those days. |
| `PLAN_EXCEL_SESSION.md` | The plan for one Excel per session (1.11.9). |
| `PLAN_SHARE_MIND_TEAM.md` | The first plan for sharing the app with the Mind team (a compiled package; replaced by a clean repository). |
