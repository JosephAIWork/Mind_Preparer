Mind Ready Beta

Gets an Excel model ready for Milliman Mind · version {{VERSION}} · {{DATE}} · from the Milliman Tel Aviv team

What it does

You give it an Excel model. It finds what Mind would refuse or read differently, fixes what it can through Excel itself, turns the model's macro run loop into a Mind loop, and recalculates to show that the model's numbers did not change. Your original file is never changed: every step makes a new version that you download.

1 Upload→ 2 Check against Mind's rules→ 3 Fix the formula errors→ 4 Fix formulas and structure for Mind→ 5 Build the Mind loop→ 6 Recalculate and compare every number→ 7 Download

Steps 3 to 6 run with one button: Do everything.

What you need

  • Windows with desktop Excel. The app writes workbooks through Excel, because saving a real model any other way can damage it.
  • The MM for Excel add-in. Without it every MM_ formula shows #NAME? and the app cannot confirm the model is ready.
  • For a large model, memory: the largest models tested needed about 7 GB free on top of Excel.
  • Optional: a key for the Milliman AI gateway, for the assistant. Every main step works without it.

Start

  1. Download MindReady.exe from the link and double-click it.
    If Windows says “Windows protected your PC”, click More info, then Run anyway.
  2. A black window opens. Keep it open: closing it stops the app. The first start takes about 20 seconds, then the app opens in your browser at http://localhost:8600.
  3. The first time, if you have an AI gateway key, paste it in the box on the main screen and click Save. It is saved encrypted for your Windows account; the app then shows only its last 4 characters.

The app runs only on your machine. Nothing is sent anywhere except the assistant's questions to the AI gateway and, when you choose it, your workbook to Mind. To change the port or the folders, put a settings.yaml next to the exe (every line is explained in the file) and restart.

Use it

  1. Drop a workbook (.xlsx, .xlsm or .xlsb).
  2. Click Do everything. It runs the fixes, each followed by its check, and stops at the first check that fails.
    Or tick Do everything right after the upload before you drop the file: it then runs from start to end without stopping to ask anything.
  3. Read the verdict on the main screen: ready for Mind, or the problems left, each with where it is and why it was not fixed.
  4. Click Download this version. You can also download the report, or the workbook with the report added as sheets.
Keep the computer awake during a long run. A small model takes a few minutes. A model with about 1.4 million formulas took about 1 hour 35 minutes. If the computer sleeps, the run waits until it wakes up.

Everything else is under Advanced: the findings rule by rule, each fix to tick or untick, the Mind loop choices, the Model map (where the inputs, the loop and the outputs are), the Grid Namer, the assistant, and every version made so far.

When something goes wrong

If a step fails, a red box under the header says in one plain sentence what stopped and why, for example “Fix the formulas: Excel did not accept 2 of the changes (rule FRM-012). The other changes were made.” Next to it is the button Send feedback to the Tel Aviv team. The same button is at the top of every screen, for anything else you want to tell us.

  1. Click the button. You can add a line about what you were doing, then click Prepare the message. The message appears: you can read it.
  2. Click Copy and open email. The message and the log are copied, and an email to {{EMAIL}} opens.
  3. Paste into the email (Ctrl+V) and send. If the email program cuts the text short, click Save as a file and attach the file.

The message is written in codes that point us to the exact place in the app, with the kind of formula involved and why it failed. For example:

Mind Ready 1.12.0 (exe) · ref 7K2Q-0915 · 27 Oct 2026 14:02 What happened FRM-012 not written at stage SS852, during "Fix the formulas" 1 change(s) not written: FRM-012 set_formula x1 FRM-012 set_formula · error EM551 · Excel code 0x800A03EC · Unable to set the Formula2 property of the Range class trace KD310:2213 > BB123:2290 before: =MID(CELL("filename",<cell>),FIND("]",CELL("filename",<cell>))+1,<n>) after: ="<text>" · one-cell array
Nothing from your workbook is in it: no file name, no sheet names, no cell addresses, no values and no text from your cells. References show only as <cell>, <range> or <name>. Read it before you send it: it is all there in plain text.

When the assistant is on (an AI key is saved), it writes the first lines of the message in plain English.

Good to know

  • The Mind loop is built only from a loop the macro already runs. The app does not invent loops or decide where a loop or instances would help.
  • MM_INSTANCE(cell, k) with k above 1 shows 0 in Mind's upload check before the first run. That is a false alarm: after a run Mind shows the right values.
  • Pivot tables: Mind refuses every pivot table, so the app turns them into values (or formulas, under Advanced, on the Prep screen).
  • External links are frozen to the values Excel last kept for them.
  • Some problems stay for a person, each listed with the reason: for example an array formula over several cells, or a text cell that a lookup reads inside a range.
