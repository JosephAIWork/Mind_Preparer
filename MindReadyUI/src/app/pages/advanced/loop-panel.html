What is this?

Mind runs no macro. The macro's run loop is written into the model as Mind's own loop formulas: MM_LOOP in the cell the macro changes (one pass per value), MM_RESULT in the block each pass writes. Mind then runs every pass itself, and the results come out the same as in Excel.
