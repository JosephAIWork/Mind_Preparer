What is this?

Mind can run several copies of one model at once: one copy per value (a scenario, a cohort, a product). Each copy computes on its own. A second, small workbook (the main workbook) gathers every copy's results with MM_INSTANCE formulas: one per result cell and copy. Mind gets both files as one project. The usual way is one model that loops (the Mind loop tab); copies help when the passes are independent and many.
